# 🎓 Eventoo – University Club Event Platform

A full-stack web application built by our student team to manage campus events.  
**Frontend**: React | **Backend**: Node.js + Express | **Database**: MongoDB  

## ✨ Features
- Create & browse university events
- Secure user authentication (JWT)
- Real-time updates & responsive design

## 🚀 Setup
```bash
# Install backend
cd backend && npm install

# Install frontend
cd ../frontend && npm install

# Run both
npm run dev # in backend
npm run dev  # in frontend


> ✏️ Replace `[Your University Name]` with your actual university!
